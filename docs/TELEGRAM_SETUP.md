
# Настройка авторизации Telegram (Обновлено)

В Supabase нет встроенной кнопки Telegram. Мы используем официальный виджет Telegram и "теневую" регистрацию.

## Шаг 1: Настройка в Telegram (@BotFather)
1. Откройте в Telegram бота **@BotFather**.
2. Используйте команду `/setdomain`.
3. Выберите вашего бота.
4. Отправьте домен вашего приложения. 
   * **Важно:** Для локальной разработки (`localhost:5173`) виджет может не работать или требовать ухищрений (например, ngrok). Лучше всего это тестировать, когда приложение уже выложено на Vercel/Netlify.
   * Если вы тестируете локально, виджет может просто не появиться или не возвращать данные.

## Шаг 2: В коде
1. Откройте файл `components/Screens/AuthScreen.tsx`.
2. Найдите переменную `const TELEGRAM_BOT_NAME = '...'`.
3. Впишите туда **username** вашего бота **без символа @**.
   * Пример: Если бот `@MyRestoBot`, пишите `'MyRestoBot'`.

## Как это работает (Shadow Login)
Поскольку Supabase не поддерживает Telegram "из коробки", мы используем хитрость:
1. Пользователь входит через виджет Telegram.
2. Приложение получает его ID (например, `12345`).
3. Приложение автоматически регистрирует пользователя в Supabase с email `12345@telegram.user` и сложным паролем.
4. Создается профиль в таблице `profiles` с именем и фото из Telegram.
5. При следующих входах приложение просто "логинит" пользователя по этим данным.
