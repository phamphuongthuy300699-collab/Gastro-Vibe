
# 💎 Gastro-OS: Операционная Система Вашего Ресторана
**Презентация продукта v2.1**

---

## 🚀 Введение
**Gastro-OS** (ранее Gastro-Vibe) — это не просто электронное меню, а гибридная платформа, объединяющая гостевой опыт, геймификацию и управление процессами зала в едином интерфейсе. Мы превращаем случайных гостей в постоянных фанатов бренда, увеличиваем средний чек через умные алгоритмы и даем персоналу инструменты "сверхспособностей".

---

## 📱 Ключевые Модули

### 1. Гостевое Приложение (Frontend PWA)
Приложение, которое открывается по QR-коду на столе. Не требует скачивания.

*   **Главный Экран "Визит" (`TableScreen`)**:
    *   **Общий счет в реальном времени:** Гости видят, кто что заказал.
    *   **Статусы блюд:** "Готовится" -> "Подано". Полная прозрачность.
    *   **Атмосфера:** Виджет текущей музыки или мероприятия.

*   **Умное Меню (`MenuScreen`)**:
    *   **Режим TikTok (Vibe Feed):** Полноэкранные видео блюд для импульсивных покупок.
    *   **Карточка товара (`ProductSheet`):** Видео-обложки, КБЖУ, конструктор модификаторов, умный кросс-сейл ("С этим берут").
    *   **Stories:** Акции и новинки в формате сторис Instagram.

*   **Клуб Привилегий (`GamesScreen` & `ProfileScreen`):**
    *   **Геймификация:** XP (опыт) за заказы, уровни лояльности (Новичок -> Гурман -> Легенда).
    *   **Игры:** "Рулетка счета" (кто платит?), "Вкусный ряд" (Match-3 для скидок), Квизы.
    *   **Секретное Меню:** Блюда, доступные только с определенного уровня.

*   **Сплит счета (`BillScreen`):**
    *   Оплата: "За себя", "Поровну" или "Вручную" в один клик.
    *   Чаевые: Удобный выбор процента.

---

### 2. Панель Управления (Admin Gastro-OS)
Профессиональный интерфейс для персонала. Доступен по тапу на "Профиль -> Настройки -> Вход".

*   **Роль: ХОСТЕС (`AdminHostView`)**
    *   **Интерактивная карта зала:** Drag & Drop управление столами.
    *   **Цветовая индикация жизненного цикла:** 
        *   🔵 Seated (Сели)
        *   🟠 Ordered (Заказали)
        *   🔴 Eating (Едят)
        *   🟢 Paying (Платят)
    *   **Timeline:** Гант-диаграмма бронирований. Визуализация конфликтов по времени.

*   **Роль: КУХНЯ / KDS (`AdminKitchenView`)**
    *   **Билетная доска:** Цифровые чеки вместо бумажных.
    *   **Агрегация:** Счетчик "Всего бургеров нужно сейчас" (All-Day count).
    *   **Таймеры:** Чеки меняют цвет (Зеленый -> Желтый -> Красный) при задержке.

*   **Роль: ОФИЦИАНТ (`AdminWaiterView`)**
    *   **Приоритизация:** Умная сортировка столов. Сверху те, кто просит счет или чья еда готова.
    *   **Уведомления:** PUSH "Кухня отдала стейк".
    *   **Fire Mains:** Кнопка "Готовить горячее" (Курсовка).

## 🎬 Сценарий Использования: "Идеальный Ужин"

1.  **Вход:**
    *   Гости (пара) заходят. Хостес на планшете видит свободный стол T2 и нажимает **"Walk-in"**.
    *   Стол T2 на карте загорается синим (Seated).

2.  **Заказ:**
    *   Гости сканируют QR. Открывается **Vibe Feed**.
    *   Девушка видит видео коктейля -> "Хочу!". Добавляет в корзину.
    *   Парень выбирает Стейк. Система предлагает: "Прожарка Medium? Добавить спаржу?".
    *   Заказ отправлен. У Официанта приходит уведомление.

3.  **Ожидание & Игра:**
    *   Пока еда готовится, гости заходят в раздел **"Клуб"**.
    *   Запускают **"Квиз"** про Италию, выигрывают 50 XP.

4.  **Кухня:**
    *   Повар видит чек на KDS. Готовит.
    *   Нажимает "Готово".

5.  **Подача:**
    *   Официант получает пуш **"Стейк Рибай - Готово"**. Забирает и несет.
    *   В приложении гостей статус блюда меняется на "Подано". Стол на карте становится красным (Eating).

6.  **Расчет:**
    *   Гости нажимают "Оплатить -> Поровну".
    *   У Официанта стол мигает зеленым (Paying).
    *   Официант подходит с терминалом или гости платят в приложении (Apple Pay).
    *   Гости получают +150 XP и переходят на уровень "Гурман".

## 💼 Бизнес-Ценность (ROI)

1.  **Рост чека на 15-20%:** За счет видео-меню и умных подсказок (Upsell) в момент выбора, которые официанты часто забывают проговаривать.
2.  **Оборачиваемость столов +10%:** KDS и быстрый расчет сокращают простои.
3.  **Возвращаемость (Retention):** Геймификация и накопление уровней мотивируют вернуться, чтобы "открыть секретный бургер".
4.  **Экономия ФОТ:** Один официант может качественно обслуживать больше столов благодаря цифровому помощнику.

## 🛠 Технический Стек
*   **Frontend:** React 18, Tailwind CSS, Framer Motion (плавные анимации).
*   **Backend:** Supabase (Realtime DB, Auth, Storage).
*   **Architecture:** Модульная, разделение Context API (UI / Data), Facade Pattern.
*   **PWA:** Работает как на iOS, так и на Android без установки.
